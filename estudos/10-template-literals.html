Template literals

Criando textos dinâmicos

Template literals são strings delimitadas por crases. Eles permitem incluir expressões JavaScript entre ${}, criando textos dinâmicos. O valor da variável name é inserido diretamente na mensagem.

let name = "Alice";
let greeting = `Olá, ${name}!`;

console.log(greeting); // Olá, Alice!
