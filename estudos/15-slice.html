Slice

Slice

Ao trabalhar com o método slice(), você frequentemente precisa extrair uma porção ou substring de uma string ou array.

let message = "Hello, world!";
let greeting = message.slice(0, 5);

console.log(greeting);  // Hello

Slice em Arrays

O método slice() também pode ser usado em arrays para criar uma cópia rasa de uma parte do array.

let numbers = [1, 2, 3, 4, 5];
let subset = numbers.slice(1, 4);
console.log(subset);  // [2, 3, 4]
console.log(numbers); // [1, 2, 3, 4, 5]
