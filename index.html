Exemplos de Código estudados sobre
variáveis, atribuições e valores.

console.log("Hello, World!");
essa mensagem é exibida no console do navegador, e é usada para testar se o código está funcionando corretamente.
let nome = "João";
console.log(nome);
let é uma palavra reservada do javascript, e é usada para declarar variáveis, e o sinal de igual é usada para atribuir
um valor a variável, e o console.log é usado para exibir o valor da variável
no console do navegador, e a variavel é nome e tem o valor de João, e é exibido no console do navegador.
