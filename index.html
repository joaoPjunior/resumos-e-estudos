Exemplo de Código: índices em strings

Entrei em uma parte dos estudos sobre indices de sequencias de
caracteres nas strings, um exemplo a seguir:
let greeting = "Hello, World!"; console.log(greeting[0]); // H
o primeiro caractere da string é acessado usando o índice 0, e o console.log exibe o valor H no console do navegador, o segundo caractere da string
é acessado usando o índice 1, e o console.log exibe o valor e no console
do navegador, e assim por diante e assim sucessivamente, até o último caractere
da string, que é acessado
usando o índice 12, e o console.log exibe o valor ! no console do navegador.

Exemplo de Código: último caractere de uma string

Para acessar também o último
caractere da string, podemos usar o índice length - 1:, um exemplo a seguir:
let greeting = "Hello, World!"; console.log(greeting[greeting.length - 1]); // !
o último caractere da
string é acessado usando o índice length - 1, e o console.log exibe o
valor ! no console do navegador.

Notas sobre template literals

Template literals são strings que permitem a inclusão de expressões JavaScript dentro de chaves `${}`. Elas são definidas com crases (`) em vez de aspas simples ou duplas.

Exemplo de Código: template literals

let name = "Alice";
let greeting = `Olá, ${name}!`;
console.log(greeting); // Olá, Alice!

Esse exemplo cria uma string dinâmica usando o valor da variável name.

Assunto sobre encontrar posições de uma substring

Para encontrar a posição de uma substring dentro de uma string, podemos usar o método indexOf().

Exemplo de Código: encontrar uma substring

let text = "Hello, World!";
let position = text.indexOf("World");
console.log(position); // 7

"World" começa no índice 7 da string.

Exemplo de Código: substring não encontrada

let text = "Hello, World!";
let position = text.indexOf("JavaScript");
console.log(position); // -1

Quando a substring não existe, indexOf() retorna -1.

Exemplo de Código: busca a partir de um índice

let text = "Hello, World!";
let position = text.indexOf("o", 5);
console.log(position); // 8

O segundo argumento define o índice a partir do qual a busca deve começar.
