Semana 1

Esta semana iniciei os estudos de JavaScript no freeCodeCamp. Foram estudados atribuições, reatribuições e concatenação de strings.

No primeiro encontro também conversamos sobre GitHub Desktop, Git Bash, commits e push. Falamos ainda sobre usar ferramentas de IA como apoio ao aprendizado, sem automatizar todo o processo.

Exemplo: console.log

O console.log() exibe informações no console do navegador e ajuda a verificar se o código está funcionando.

console.log("Hello, World!");

Variáveis, atribuições e valores

A palavra-chave let declara uma variável. O sinal de igual atribui um valor a ela, que pode ser exibido com console.log().

let nome = "João";
console.log(nome);

Concatenação de strings

A concatenação une duas ou mais strings. Neste exemplo, o operador + junta o nome, um espaço e o sobrenome.

let firstName = "João";
let lastName = "Silva";

console.log(firstName + " " + lastName);

Semana 2

Nesta semana continuamos os estudos de JavaScript, com revisão de funções, tipos de dados, typeof, números, strings e valores booleanos.

JavaScript é uma linguagem de tipagem dinâmica: o tipo de um valor pode mudar durante a execução. Em linguagens de tipagem estática, como C#, os tipos são definidos e verificados com regras mais rígidas.

Também estudamos formas de concatenar strings, incluindo o operador += e template literals, que facilitam montar frases com valores de variáveis como nome, idade e sexo.

Índices em strings

Os caracteres de uma string são acessados por índices, que começam em zero. Assim, o primeiro caractere de greeting é H.

let greeting = "Hello, World!";
console.log(greeting[0]); // H

Último caractere de uma string

Para acessar o último caractere, usamos o tamanho da string menos um: length - 1.

let greeting = "Hello, World!";
console.log(greeting[greeting.length - 1]); // !

Quebra de linha e caracteres especiais

O caractere \n cria uma nova linha dentro de uma string. Para incluir caracteres especiais, como aspas, também é possível usar o caractere de escape \.

let message = "O Senhor é meu Pastor\nNada me faltará";
console.log(message);

Template literals

Template literals são strings delimitadas por crases. Eles permitem incluir expressões JavaScript entre ${}, criando textos dinâmicos.

Exemplo: template literals

O valor da variável name é inserido diretamente na mensagem.

let name = "Alice";
let greeting = `Olá, ${name}!`;

console.log(greeting); // Olá, Alice!

Encontrando posições de uma substring

O método indexOf() encontra a posição de uma substring dentro de uma string. Se ela não for encontrada, o resultado é -1.

Exemplo: encontrar uma substring

Neste caso, World começa no índice 7.

let text = "Hello, World!";
let position = text.indexOf("World");

console.log(position); // 7

Exemplo: substring não encontrada

Como JavaScript não está presente no texto, indexOf() retorna -1.

let text = "Hello, World!";
let position = text.indexOf("JavaScript");

console.log(position); // -1

Exemplo: busca a partir de um índice

O segundo argumento informa a partir de qual índice a busca deve começar.

let text = "Hello, World!";
let position = text.indexOf("o", 5);

console.log(position); // 8

Métodos charAt() e charCodeAt()

charAt() retorna o caractere de uma posição específica. Já charCodeAt() retorna seu código Unicode.

let str = "Hello";

console.log(str.charAt(1)); // e
console.log(str.charCodeAt(1)); // 101

No índice 1 está o caractere e, cujo código Unicode é 101.

Diferença entre includes() e indexOf()

includes() retorna true ou false, informando se a substring existe. indexOf() retorna o índice da primeira ocorrência ou -1 quando ela não é encontrada.

let str = "Hello, World!";

console.log(str.includes("World")); // true
console.log(str.indexOf("World")); // 7

Nesse exemplo, World existe na string e começa no índice 7.
